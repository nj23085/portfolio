Trust-Score

An AI-powered system that detects fake and deceptive product reviews across Indian e-commerce platforms. It is the production-oriented evolution of my Fake Review Detection project.

Scrape reviews→Extract features→Classify→Trust-score dashboard

What it does

  • Classifies each review as genuine or deceptive and aggregates a trust score per product.
  • Flask web app with a real-time dashboard, charts and per-review classification.
  • Browser extension with popup and content-script scrapers for Amazon, Flipkart and Myntra.

Signals used

  • Word and character TF-IDF vectorization.
  • Review length, exclamation and uppercase ratio, unique word ratio.
  • Rating, verified-purchase flag, review bursts and helpful-vote count.
  • Classifiers targeting 95–97% accuracy.

AdaptiRAG

An adaptive hybrid graph-vector RAG platform that routes each question to the retrieval strategy most likely to answer it well, and cites its sources.

Question→Adaptive router→Vector search + knowledge graph→Cited answer

Retrieval

  • FAISS vector search for semantic matches.
  • Knowledge graph with Louvain community detection.
  • Adaptive router chooses the path per query.

Platform

  • FastAPI backend in Python.
  • React and TypeScript frontend.
  • Answers returned with citations.
